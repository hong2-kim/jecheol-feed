# 사용자가 보낸 사진과 동영상 (`myphotos/index.json`)

> 언제 읽나: `myphotos/index.json` 에 `plan` 이나 `side` 가 오늘인 안 쓴 항목이 있을 때. 공통 규칙은 `PROMPT.md`. (2026-10-19 PROMPT.md 에서 옮겨 왔다. 고친 곳은 `docs/stage3-rule-split.md`)

## 사용자가 보낸 사진과 동영상 (`myphotos/index.json`)

사용자가 식당에서 직접 찍어 텔레그램으로 보낸 사진과 동영상의 기록이 `myphotos/index.json` 에 있다. **하루에 하나씩, 그날 저녁 메뉴 영상의 주인공으로 쓴다.**

### 오늘 쓸 것 찾기

- `index.json` 에서 **`plan` 이 오늘 날짜**이고 `used` 가 비어 있고 `deleted` 가 없는 항목을 찾는다. **많아야 하나다.**
- `plan` 은 자동으로 정해진 "쓸 날짜"다. **`plan` 이 다른 날인 항목은 오늘 쓰지 않는다.** 여러 개가 쌓여 있어도 하루에 몰아 쓰지 않는다. `plan` 값은 고치지 않는다.
- 오늘 쓸 항목이 없으면 이 절은 건너뛰고 평소대로 만든다.
- **`side` 가 오늘 날짜인 항목**(`plan` 이 없다)은 따로 본다. 며칠 전에 쓴 것과 비슷한 음식이라(`side_of` 에 그 음식 이름) 한 주 미뤄 둔 것이다. 사용자가 정했다: 같은 음식이 연달아 주인공이 되지 않게, **첫 장면에 쓰지 않고 메뉴 카드 한 장에만** 넣는다. 아래 "미뤄 둔 것 넣기"를 따른다.

### 무엇인지 보기

- 사진은 `python scripts/photos.py get <file 주소> /tmp/a.jpg`, 동영상은 미리보기 그림을 `python scripts/photos.py get <thumb 주소> /tmp/a.jpg` 로 받아 Read 로 연다.
- `note` 는 사용자가 함께 적은 말이다(음식 이름, 가게, 지역, 한마디). 사용자가 직접 겪은 일이므로 그대로 써도 된다. 적혀 있지 않은 내용은 지어내지 않는다.

### 넣는 방법: `3-dinner.json` 의 4칸 중 한 칸

- **오늘 저녁 추천 4칸 중 한 칸(가능하면 썸네일 사진도)을 그 음식으로 한다.** 칸에 `{"photo": {"url": "<file>"}}` 로 적는다. 동영상이면 미리보기 그림(`thumb` 주소)을 사진으로 쓴다(칸에는 영상을 넣지 않는다).
- 그 음식을 말하는 문장은 `note` 에 적힌 만큼만 쓴다(지어내지 않는다). 나머지 3칸은 평소대로 고른다. 사용자가 보낸 다른 자료를 여기에 넣지 않는다.

### 미뤄 둔 것 넣기 (`side` 가 오늘인 항목)

- `3-dinner.json` 의 4칸 중 **썸네일이 아닌 한 칸**에 넣는다. 썸네일 사진은 `plan` 이 오늘인 항목이나 평소대로 고른 메뉴의 것이다.
- 사진이면 `{"photo": {"url": "<file>"}}`, 동영상이면 미리보기 그림을 사진으로 적는다. 다른 칸과 똑같이 그 음식을 한 문장으로 소개한다.
- 그날 다른 메뉴는 이것과 비슷하지 않은 음식으로 고른다. `side` 값은 고치지 않는다.
- 쓴 뒤에는 아래와 같이 `used` 에 적는다.

### 쓴 뒤

- 쓴 항목의 `used` 에 `"2026-10-13/3-dinner"` 처럼 적고, 커밋에 `myphotos/index.json` 을 함께 넣는다. **한 번 쓴 것은 다시 쓰지 않는다.**
- `index.json` 의 다른 값(`id`, `sha256`, `tg_unique`, `look`, `plan` 등)은 고치거나 지우지 않는다. 이 기록은 파일이 지워진 뒤에도 남아 같은 것이 다시 쓰이는 것을 막는다.
- 직접 찍은 것은 `credits` 에 적지 않는다.
