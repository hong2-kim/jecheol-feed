## 2. 자동 게시인가, 사용자 게시인가

| 채널 | 방식 | 사람 손 |
|---|---|---|
| 인스타그램 릴스·카드 | 텔레그램으로 영상·게시글만 옴 → **사용자가 직접 올림** | 있음 |
| 유튜브 쇼츠 | 텔레그램으로 제목·설명·내려받기 주소 → **사용자가 직접 올림**(자동 업로드 안 씀) | 있음 |
| 네이버 블로그 | 13:00 윈도우 예약 작업이 **자동 발행**(공개) | 없음 |
| GitHub 릴리스·Pages·RSS | produce·publish 작업이 **자동 공개** | 없음 |

- SNS 게시는 사용자 손을 거치지만, **영상 파일 자체는 매일 자동으로 공개 웹에 올라간다**(공개 저장소 릴리스). "게시 안 했으니 공개 안 됨"이 아니다.
- 네이버 자동 발행은 지금까지 보관함 사진을 쓴 적이 없고, 발행 프로그램도 `vault:` 주소를 읽지 않는다. 다만 `PROMPT.md` 가 "블로그 사진 어디든 된다"고 적어 두어 규칙상으로는 열려 있다.

## 8. 승인 뒤 순서 (제안)

1. 사용자: u-… 7장 + 돈까스 2장이 직접 찍은 것인지 답하기(가장 빠른 정리).
2. `PROMPT.md` 보관함 절: "권리 확인 목록에 있는 사진만, 지정 3장은 확인될 때까지 지정 해제" + `produce.py` 차단. 하루 실행을 지켜본다.
3. CC BY 표시 보강(라이선스 주소·유튜브 설명·제목) 후 저녁·카드 뉴스에 1~2장 허용.
4. 관광공사 국문 관광정보 이미지(1유형만) 검색을 `photos.py` 에 추가. 그 전에 TourAPI 안내서로 유형 칸 이름 확인.
5. 사용자가 `_검토목록.csv` 를 채우는 대로 보관함 사진을 다시 연다.
6. (따로 결정) 발견형·트렌드의 회사·기사 사진 기준.
