# 인기 쇼츠 편집 기법 흡수 (2026-11-18 시험, 승인 전)

이 문서와 `video/voice.py` 의 새 기능은 **시험 브랜치에만** 있어요. main·운영 자동화에는 아직 반영하지 않았어요.
새 기능은 모두 설계도에 **적은 영상만** 써요. 적지 않은 기존 영상(저녁 추천·축제·이야기·내레이션)은 화면이 바뀌지 않아요.

## 이미 있던 기능 (새로 만들지 않음)

| 기능 | 설계도 | 비고 |
|---|---|---|
| 한 문장 안에서 사진 여러 장 빠르게 바꾸기 | 문장 `"photos": [a, b]` | 말 조각이 바뀌는 때에 맞춰 바뀜(0.6초 이상 간격) |

| 사진 일부만 잘라 쓰기 | 사진 `"crop": [왼, 위, 오른, 아래]` | 원본 픽셀. 작으면 키움 |
| 사진 위치 | 사진 `"pos"` | object-position |
| 통째로 보이기 | 사진 `"fit": "contain"` | |
| 가격·수치 막대 | `"card": {"type": "bars"}` | |
| 가격 근거 자동 확인 | 설계도 `"facts"` | 대사 속 금액이 근거와 다르면 막음 |

## 새로 만든 기능 (video/voice.py, 시험)

| 기능 | 설계도 | 화면 |
|---|---|---|
| 사진 확대·이동 | 사진 `"move": "in"·"out"·"left"·"right"·"up"·"down"` 또는 `{"zoom": [1.0, 1.2], "focus": ["50% 50%", "45% 55%"]}` | 그 사진이 보이는 동안 천천히 확대·이동. 분할 카드 안 사진에도 됨 |
| 번호 표시 | 문장 `"badge": "1/3"` | 사진 칸 오른쪽 위 노란 원(1 / 3) |
| 위아래 분할 비교 | `"card": {"type": "split", "mid": "VS", "rows": [위, 아래], "src": "..."}`, 줄마다 `{"photo", "label", "value", "was", "hl"}` | 위아래 사진 두 장 + 이름표. 아래 이름표는 묶음의 둘째 문장이 시작될 때 나옴. `was` 는 지운 값(정가) |

## 장르별로 쓸지 말지 (무조건 쓰지 않음)

| 장르 | move | badge | split | 쓰는 때 |
|---|---|---|---|---|
| 편의점·신상 (10-voice) | 씀 | 2개 이상 연달아 소개할 때 | 가격 차이(따로 vs 세트, 정가 vs 할인)가 사실로 있을 때 | 이번 시험 |
| 저녁 추천 (3-dinner, rec 화면) | 쓰지 않음 | 쓰지 않음 | 쓰지 않음 | rec 화면은 따로 그려요(rec.py). 옮기려면 따로 승인 |
| 일반 먹거리 해설 | 사진이 정지돼 보일 때만 | 순위·여러 개일 때만 | A vs B 비교 소재일 때만(갈치 은/먹, 국산 vs 수입) | |
| 축제 | 포스터는 쓰지 않음(`fit: contain` 원칙) | 쓰지 않음 | 올해 vs 작년 일정처럼 비교일 때만 | |
| 이야기 (6-story) | 감성 사진에 느린 `in` 정도 | 쓰지 않음 | 쓰지 않음 | |

## 남은 문제

- **회사 보도 사진 편집 범위**: `docs/photo-rights-press.md` 는 "크기 조절·흰 여백 자르기까지"예요. `crop`·`move` 로 제품만 크게 보이는 것은 그 범위를 넘어요. 사용자 결정이 필요해요.
- **사진 권리**: GS리테일·세븐일레븐 모두 `sources.json` 에서 '확인 필요(회사 확인 필요)'. 시험 영상은 올리지 않아요.
- 엔진의 영상 조각(`"video"`)은 소리를 빼요. 원본 소리(지글지글)는 아직 못 써요.
