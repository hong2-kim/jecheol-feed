### 남은 문제·한계
- 구글 뉴스 검색은 따옴표를 써도 느슨해서 관계없는 글이 섞인다(예: `"세븐일레븐" 출시` 에 게임 협업, `"1인 가구"` 에 지역 행정 소식). 고르는 것은 여전히 루틴의 판단이다.
- 편의점 4사·식품기업·프랜차이즈 누리집은 RSS 가 없어 자동으로 모으지 못하고, 검색어와 `pages`(확인용)로만 다룬다. 투썸플레이스 누리집은 자동 접속이 403.
- 정책브리핑(korea.kr) 부처별 RSS 주소는 404였다. 농식품부 발표는 검색어로만 모은다.
- 인기 기사 순위·공개 조회수는 모으지 못한다(공개 RSS 없음). 매체 수(`coverage`)로만 본다.
- inbox 가 하루 수백 건 늘어 루틴이 읽을 양이 늘어난다. `PROMPT.md` 는 약 37KB → 41KB.
- `cards.md` 31줄은 그대로다(4단계). 지금 `main` 의 규칙으로 내일 06시 루틴이 돈다.
